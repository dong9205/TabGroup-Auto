# TabGroup Auto

智能标签组管理助手 — 自动将新标签页归类到指定标签组，让浏览更有条理。

---

## 功能介绍

自动将新打开的标签页加入指定标签组，并支持按 URL 规则批量归类与排序，方便管理和查找标签页。

### 主要特性

- **默认标签组**：新开标签页自动加入所选标签组
- **独立窗口识别**：可选「不将独立窗口的标签页加入标签组」（如划词翻译等小窗口）
- **URL 规则**：按 URL 匹配（如 `*github.com*`），将匹配的标签页归入指定标签组，支持「应用规则到所有标签页」与「强制移动已分组标签页」
- **标签组与排序**：在弹窗中创建新标签组、一键排序所有标签页
- **可选公网同步（手动）**：仅同步“已分组”的标签页，使用同步口令在本机派生密钥进行加密后上传到你自己的 Worker（服务端只存密文）
- **本地运行**：未开启公网同步时，配置存储在浏览器本地，不收集、不上传任何用户数据

## 安装与使用

### 安装方式

1. 克隆或下载本仓库
2. 打开 Chrome 或 Edge：`chrome://extensions`（Edge 为 `edge://extensions`）
3. 开启「开发者模式」，点击「加载已解压的扩展程序」
4. 选择本项目的根目录

### 基本使用

1. 安装后点击工具栏中的扩展图标打开弹窗
2. **选择默认标签组**：在「选择默认标签组」中勾选要使用的组
3. **独立窗口**：若需排除划词翻译等独立小窗口，勾选「不将独立窗口的标签页加入标签组」
4. 点击「保存设置」生效

### 进阶配置

- **URL 规则**：在弹窗的「URL规则配置」中填写匹配串（如 `*github.com*`）、选择目标标签组，可添加多条规则，并随时「应用规则到所有标签页」
- **标签页排序**：在弹窗中点击「一键排序所有标签页」即可按当前规则整理顺序
- **选项页**：通过扩展右键菜单进入「选项」可进行更完整的配置（与弹窗中的设置一致）

### 公网同步（可选 / 手动）

用于跨地点（公司/家里）同步“所有标签组”（仅分组标签，不同步未分组标签）。

**工作方式**：
- 扩展收集所有窗口中已分组的标签页 URL + 标签组元数据（标题/颜色/折叠状态）
- 使用你在选项页配置的“同步口令”在本机派生 AES-GCM 密钥，将快照加密后上传到 Cloudflare Worker（KV 里只存密文）
- 另一台设备使用相同口令拉取并解密，再复原到当前窗口

**部署与配置**：
- Worker 示例脚本：`cloudflare-worker.js`
- 在 Worker 中绑定 KV：`TABGROUP_AUTO_SYNC_KV`
- 在扩展选项页填写 Worker Base URL（默认：`https://tab.p-pp.xyz`，可改为你自己的域名）和同步口令
- 在弹窗点击「上传所有标签组 / 拉取并复原到当前窗口」

**同步扩展配置**：
- 在弹窗点击「上传扩展配置 / 拉取并应用配置」
- 当前会同步：默认标签组标题、独立窗口忽略开关、URL 规则、分组排序配置、默认排序方式、域名层级数
- 不会同步：同步口令、Worker 地址、设备标识等敏感或设备相关配置

**安全说明（弱口令风险）**：
- 同步数据会在本机加密后上传，服务端仅保存密文。
- 如果同步口令过弱，且云端密文被他人获取，仍可能被离线穷举猜解。
- 该版本在本机使用 PBKDF2 派生密钥，并在每次上传时生成随机 salt，以降低预计算攻击收益；仍强烈建议使用 16+ 位强口令。

## 隐私说明

默认情况下，本扩展不收集、不上传任何用户数据，所有设置均保存在本机的浏览器存储中。

如果你在选项页启用了「公网同步（手动）」，扩展会把“已分组标签页信息”加密后上传到你配置的 Worker 地址（服务端只存密文，不包含明文 URL/标题）。

更多说明见 [privacy-policy.html](privacy-policy.html)（若已安装扩展，可从扩展详情页进入）。

  - 新增公网同步（手动）：同步所有标签组（仅分组标签），支持跨设备拉取并复原到当前窗口
