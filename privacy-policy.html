TabGroup Auto 隐私政策

最后更新日期：2026年1月

信息收集和使用

默认情况下，TabGroup Auto 扩展程序不会向任何外部服务器上传用户数据。所有配置信息（如默认标签组设置）均存储在用户本地浏览器中。

可选的公网同步功能（手动）

如果用户在选项页启用了「公网同步（手动）」并配置了自己的 Worker 地址，扩展会在用户点击同步按钮时：

  • 收集所有窗口中「已分组」的标签页信息（主要为 URL）以及标签组元数据（标题/颜色/折叠状态）
  • 可选：收集扩展配置（例如 URL 规则、排序配置等）
  • 使用用户设置的同步口令在本机派生密钥，对快照进行 AES-GCM 加密
  • 将加密后的密文上传到用户配置的 Worker（服务端只存密文）

同步口令仅保存在用户本机浏览器存储中，不会上传到任何服务器。若用户遗忘口令，将无法解密既有云端密文数据。

权限说明

本扩展程序请求以下权限：

  • "tabs" - 用于管理和组织浏览器标签页
  • "tabGroups" - 用于管理标签组
  • "storage" - 用于在本地存储用户设置
  • "windows" - 用于识别浏览器窗口类型
  • "host_permissions" (https://*/*) - 用于在用户启用公网同步时访问其配置的 Worker 地址

数据存储

所有设置数据仅保存在用户的本地浏览器中，使用 Chrome Storage API 进行存储。

若用户启用公网同步功能，扩展会把加密后的快照上传到用户配置的 Worker。该数据为密文，服务端不包含明文 URL/标题。
